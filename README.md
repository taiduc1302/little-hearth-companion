# Тихолесье · локальный прототип 0.2

Уютный питомец и дом для совместных занятий. Актуальное направление: **обустроить место → сделать вещь вместе → оставить её дома**.

## Начать

Требуются Node.js 22+ и pnpm. В этой папке:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть адрес, показанный Vite (обычно http://127.0.0.1:5173/). `pnpm check` запускает TypeScript, тесты, проверку форматирования и production build. `pnpm preview` показывает собранный dist. Приложение рассчитано на корень сайта; публикация не выполнялась.

## Что можно сделать

Угостить/погладить/умыть питомца, выбрать один из двух уголков и шарф, получить две истории, переименовать соседа. В мастерской выбрать одно из двух мест и материалов, создать открытку из двух мотивов и двух цветов, оставить её в комнате. Черновик и готовая работа переживают перезагрузку. Повтор открытки не даёт валюту или XP. На выставке хранится одна готовая работа, новая её заменяет.

Сохранение в IndexedDB локально для браузера и origin. Есть проверка схемы, резерв предыдущей записи, явное восстановление и защита от конкурирующих вкладок. Версия схемы 2; старый формат 1 проверяется и переносится без потери старых полей, физическая запись нового формата происходит при следующем действии. Старый клиент не должен открывать формат 2. Экспорт JSON есть; импорт пока отсутствует. Очистка данных браузера удаляет локальную игру.

## Границы

Это короткий игровой эксперимент, не готовая мобильная игра. Нет аккаунтов, магазина, облака, соцсети, произвольного размещения мебели и полноценного самостоятельного поведения. Графика оригинальная SVG/Pixi; места и инструменты мастерской пока схематичные. Выбор мотива/цвета — композиция, не свободное рисование. Удовольствие и удержание ещё не проверялись на людях. Не копируем персонажей, названия или ассеты исторических игр.
