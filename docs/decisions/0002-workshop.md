# ADR 0002: сохраняем каждый шаг совместной работы

Принято 15 сентября 2026. Domain остаётся единственным местом правил; UI отправляет команды. Выставка содержит один immutable snapshot, следующий finish заменяет его. Черновик независим от выставки, отмена не затрагивает готовую работу. Повторный finish без черновика отклоняется. Ни одна команда мастерской не изменяет экономику.

Schema 2 добавляет workshop. parseGame сначала валидирует старые данные при schemaVersion=1, затем добавляет пустую мастерскую. В read-only load физически не переписываем старое сохранение. Следующая атомарная команда сохраняет новую схему и резерв; concurrent старый клиент получит конфликт ревизии либо newer-version отказ. База IndexedDB сохраняет прежнее имя, иначе игрок потерял бы доступ к своему дому.

Готовая открытка отображается SVG поверх комнаты и в панели. Это одинаково работает без WebGL. Варианты места/материалов пока схематичные; полноценные ассеты и анимационные привязки отдельная задача. Приобретённое поведение не заявляем реализованным.
