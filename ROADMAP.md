# Дорожная карта после пересмотра ядра

Оценки сроков раннего плана не являются обязательствами. Каждый этап открывается после проверки предыдущего. Завершённый код отличается от целевого MVP.

| Версия | Содержание | Gate |
|---|---|---|
| 0.1 — готово | Забота, два готовых уголка, две истории, локальная запись | Базовая цепочка и отсутствие повторных наград |
| 0.2 — текущий срез | Роли места/материалов, композиция открытки, сохранённый черновик, выставка | Автотесты + браузер; затем 8–12 пользовательских наблюдений |
| 0.3 — целевой MVP | Реальное освоение занятия питомцем, три занятия, ограниченный каталог, цели и экономика | Игроки объясняют причинную связь предметов/поведения; недельная симуляция баланса |
| 0.4 — мир | Сад, авторские NPC, детерминированный крафт, расширение дома | Себестоимость контента, доступность одиночного прохождения |
| 0.5 — упаковка | Мобильная производительность, экспорт снимков, доступность, импорт резервов | Реальные устройства, восстановление, пользовательская проверка |
| 0.6 — добровольное облако | Аккаунт, копии, конфликты, удаление | Испытания потери связи/устройства и приватности |
| 0.7 — закрытая социальная beta | Визиты опубликованных домов, безопасные подарки/письма | Модерация, возрастные требования, блокировка/жалобы готовы до включения |
| 0.8 — подготовка релиза | Совместимость, нагрузка, эксплуатация, контент-план | Два пробных выпуска и закрытые дефекты |
| 1.0 — решение о выпуске | Завершённая первая глава, выбранная коммерческая модель | Человеческое принятие, надёжность и подтверждённая ценность |

Следующий наиболее ценный шаг после 0.2 — наблюдать игроков, а затем сделать осмысленную самостоятельную реакцию питомца на конкретное созданное место. Не увеличивать число косметических карточек до этого решения.
